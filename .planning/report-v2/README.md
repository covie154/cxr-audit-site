# Report v2 planning pack

Start with [DESIGN.md](DESIGN.md), then [EXECUTION-RUNBOOK.md](EXECUTION-RUNBOOK.md).

- [IMPLEMENTATION-PLAN.md](IMPLEMENTATION-PLAN.md): five delivery stages and release scope.
- [EXECUTION-RUNBOOK.md](EXECUTION-RUNBOOK.md): 19 bounded tasks for Qwen/Terra or equivalent.
- [YAML-CONTRACT.md](YAML-CONTRACT.md): syntax, semantic checks and result contracts.
- [report.schema.json](report.schema.json): proposed structural JSON Schema.
- [prime-overview.yaml](prime-overview.yaml): 17-widget initial legacy-layout draft.
- [lunit-defaults.v1.yaml](lunit-defaults.v1.yaml): current default thresholds, not upcoming new values.
- [LEGACY-MAP.md](LEGACY-MAP.md): parity map and intentional differences.

These are planning artifacts, not deployed functionality. Runtime schema validation, measurement services,
editing, publishing and report rendering beyond the shell remain to be implemented. The existing HIPAA
roadmap is unchanged. Sources and implementation facts are documented in DESIGN.md.
